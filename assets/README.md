# Identity assets

These lightweight SVGs are original 11 October artwork. They share a near-black field, warm ivory eclipse, thin orbital line, and one orbiting point. They use shapes and text only; no external logo or font file is embedded.

- **eleven-october-mark.svg** — compact eclipse mark.
- **eleven-october-wordmark.svg** — mark with the organization name and identity.
- **eleven-october-banner.svg** — wide version for the organization profile.

The SVGs include a title and description and scale through their viewBox. Keep the source editable. If adapting an asset, record the change and retain attribution under the repository’s [CC BY 4.0 license](../LICENSE). The license does not allow use of the name or marks to imply endorsement.
