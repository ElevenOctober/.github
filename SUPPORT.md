# Support

Use the route that matches the request:

- To report an existing engineering problem, use the [problem submission form](https://github.com/ElevenOctober/.github/issues/new?template=problem-submission.yml).
- To propose an approach, first use the [engineering proposal form](https://github.com/ElevenOctober/.github/issues/new?template=engineering-proposal.yml) and include an accepted Problem ID.
- To correct this repository’s guidance, use the [documentation form](https://github.com/ElevenOctober/.github/issues/new?template=documentation.yml).
- For an existing project, open an issue in that project’s repository and include its Problem ID when available.
- For security concerns, follow [SECURITY.md](SECURITY.md). Do not post vulnerability details publicly.
- For conduct concerns, follow the private process in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

A problem submission is not an acceptance. Maintainers may ask for more context, decline the request, or archive it when it cannot be verified or responsibly pursued.

Issues are public. If a problem cannot be described without revealing private or sensitive details, do not submit it here; ask a maintainer through a private channel you already trust for a safe intake route. No dedicated private intake address is currently published.
